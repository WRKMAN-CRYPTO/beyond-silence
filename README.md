# beyond-silence

**Ever wondered what sound tastes like?**

A playground for learning sound by touching it, bending it, breaking it, and keeping whatever survives.

## Toy 001 — Glass Fruit

Touch the dark. Horizontal movement changes pitch. Vertical movement changes the material of the sound. Pluck it. Drag it. Listen for where the tone stops feeling like a number and starts feeling like an object.

No roadmap. No obligation to be useful.
